## 🧑‍💻 About me

I love understanding how things work under the hood — from a CPU instruction to a full game loop.
Most of my projects are **emulators**, **engines** and **simulations** written in C++ (and a bit of Rust), often ported to the **web with WebAssembly**.

- 🔭 Currently building **GenesisForge**, my own C++20 game engine (ECS, JSON scenes, engine + editor, web demo)
- 🎮 Modding **Final Fantasy VIII Remastered** to bring back full 360° analog movement
- 🕹️ Writing emulators for fun: Chip-8, Game Boy, NES, Space Invaders arcade
- 🌱 Always learning — low-level, graphics programming and game architecture
